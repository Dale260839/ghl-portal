## Delivered — Phase A groundwork (no keys required)

Most of the live-data work doesn't need credentials. Only the response *shapes*
do, and those are quarantined in one file.

- **GHL API client** — auth headers, timeouts, typed errors, and a retry policy
  that separates retryable from permanent. 429 honours `Retry-After`; 5xx and
  network failures back off; **401 and 400 never retry**. Backoff is jittered,
  because the sync-back fires every project on the same hourly schedule and
  unjittered retries would hit the rate limit in lockstep.
- **Response mapper** — the only file that is guessing. When Phase 0 returns real
  JSON it is a one-file correction rather than a rewrite. Checkbox coercion
  defaults to **false**: `Client Portal Enabled` is a clause of the §9.1 gate, so
  an unparseable value must close the gate, never open it.
- **`GhlDataSource`** — implements the interface the screens already use.
  `getDataSource()` picks it when fully configured and falls back to fixtures
  otherwise, warning loudly on a half-configured environment. All-or-nothing on
  purpose: three real projects and two invented ones is worse than an obvious demo.

## Enforcement — now automated, not hand-checked

Client reads run through a projection that applies the §9.1 gate, then builds an
explicit **allow-list** DTO rather than filtering a deny-list — so a new internal
field cannot reach a client by default. `assertNoInternalFields` is the backstop.
The server-only guard is structural: pull it into a client component and the
build fails.

This morning's checks were manual curls against the running app, which proves it
was safe today. They are now **14 automated tests**, including value-level checks
that survive a field rename:

| Check | Result |
|---|---|
| Original estimate, markup, margin, internal notes, delay reason in a client projection | **0** |
| Unpublished / internally-approved updates reaching a client | **none** |
| A contact projecting a project they aren't associated with | **denied** |
| Switches off → budget, team, completion date | **withheld** |

**67 tests green** (33 web, 34 contracts). Production build clean.
