## Field / status vocabulary to build to (Artifact-verbatim)

When these get built, use these names exactly (D-021):

**Sync fields (88/91):** `projecthub_project_id`, `buildsuite_project_id`,
`ghl_contact_id`, `ghl_opportunity_id`, `project_status_internal`,
`client_status_label` (a.k.a. `project_status_client`), `milestone_current`,
`field_update_review_status`, `change_order_status`, `closeout_status`,
`warranty_review_status`, `payment_status_language`.

**Project statuses (88), client-visible subset in parentheses:** INTAKE_REVIEW,
SCOPE_BUILD, ESTIMATE_REVIEW, PROPOSAL_READY, CLIENT_DECISION, SCHEDULE_SETUP,
ACTIVE_WORK ("Work In Progress"), WAITING_MATERIALS, INSPECTION_PENDING,
CHANGE_ORDER_PENDING, DELAY_REVIEW ("Schedule Update Pending"), PUNCH_LIST,
CLOSEOUT_REVIEW, COMPLETED, WARRANTY_REVIEW, ON_HOLD, ARCHIVED.

**Change-order statuses (89):** Change Triggered → Under Contractor Review →
Draft Change Order → Internal QA Required → Ready for Client Review → Client
Review Pending → Approved / Rejected / Revision Requested → Synced → Closed.
(Client projection models only the last client-visible states — see C-3.)

**Field-update review statuses (85/86):** Submitted / Pending Review, Needs
Clarification, Approved Internal, Approved for Client, Published to Client,
Escalated, Rejected/Duplicate.

**Photo categories (86):** Before, Progress, After, Issue/Blocker, Material,
Inspection/Compliance, Closeout. Default handling: Issue/Material/Before →
internal review first; Progress/After → eligible for client after approval.

**Plan tiers (83):** Intro $1/mo (3 uses), Starter $198 (5), Core $498 (15),
Pro $998 (25), Master $1,998 (unlimited). ProjectHub eligibility starts at
Core+/Digital Silver+ per Artifact 25.

## Warranty / Alliance Protection — the language rule (90)

Never state or imply coverage. Only *review* language: "under review",
"eligibility being confirmed". Coverage is conditional on membership, project
eligibility, ProjectHub documentation, agreement/addendum, and AFC admin review.
This is a legal-weight boundary — build nothing here until the policy exists.
