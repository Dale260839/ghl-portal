## Changes

- Crew invitations and password resets now activate the password and consume the link in one Hub transaction. Simultaneous redemptions serialize on the membership; other pending links for that membership are revoked after success. A failed transaction consumes nothing.
- Password changes increment a membership credential version. Older signed sessions fail the next protected read or write. Existing version-zero sessions remain valid until a password change; this release does not rotate credentials.
- Verified GHL contractors can open their own workspace in a standalone tab. Opening links are random, single-use, expire within two minutes, and preserve the original session deadline and tenant scope. The token travels in a URL fragment that is immediately removed and is redeemed by same-origin POST. No crew/homeowner handoff or unsigned contractor login was added.
- Phone/tablet headers yield space correctly; operator controls remain accessible. The new open control is an icon button with an accessible name and tooltip.
- The homeowner dashboard uses released update publication dates, not the commercial project's old date. Completed/past milestones are not advertised as upcoming. Unscheduled milestones display clear date labels.
- Expired, signature-valid embedded session cookies can still be cleared with their original partitioning attributes.
